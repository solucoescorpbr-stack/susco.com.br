Política de Privacidade — TNCalc

Última atualização: 27 de julho de 2026

Este documento descreve como o TNCalc, aplicativo desenvolvido pela Support Soluções Corporativas Ltda ("Susco"), coleta, usa, armazena e protege dados no contexto de um aplicativo profissional de prontuário de nutrição, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Quem somos

O TNCalc é desenvolvido e operado pela Support Soluções Corporativas Ltda ("Susco"), pessoa jurídica de direito privado. O TNCalc é um aplicativo destinado a profissionais de nutrição (nutricionistas) para uso em prontuário de terapia nutricional, cálculos antropométricos e triagens de risco nutricional.

2. Quem é o titular dos dados

Neste aplicativo existem dois grupos de dados pessoais:

  • Dados do profissional (usuário da conta): nome, e-mail e registro profissional (CRN), usados para autenticação e identificação do responsável técnico pelos registros.
  • Dados dos pacientes: inseridos pelo profissional de nutrição para fins de prontuário clínico, incluindo dados de saúde (peso, estatura, diagnósticos, resultados de triagens nutricionais). Dados de saúde são considerados dados pessoais sensíveis pela LGPD.

O profissional de nutrição que utiliza o TNCalc é responsável, na qualidade de controlador desses dados de pacientes, por obter o consentimento adequado (ou outra base legal aplicável, como a tutela da saúde) junto aos seus pacientes ou responsáveis legais, conforme as normas do seu conselho profissional e a legislação aplicável.

3. Quais dados coletamos

  • Dados de cadastro do profissional: nome, e-mail, senha (criptografada), registro profissional.
  • Dados clínicos inseridos sobre pacientes: identificação básica, dados antropométricos, resultados de triagens e avaliações nutricionais, metas nutricionais, anotações de evolução clínica.
  • Dados de uso e diagnóstico técnico do aplicativo (ex.: registros de erro), para manutenção e melhoria do serviço.
  • Dados de assinatura/pagamento: processados diretamente pela Apple App Store (e, futuramente, Google Play), que atua como processador de pagamento. O TNCalc não armazena dados de cartão de crédito.

4. Como usamos os dados

  • Fornecer as funcionalidades do aplicativo (cadastro de pacientes, cálculos, triagens, geração de relatórios em PDF).
  • Autenticar o profissional e proteger o acesso aos dados por meio de isolamento por conta (cada profissional só acessa seus próprios registros).
  • Processar assinaturas do plano Pro.
  • Cumprir obrigações legais e regulatórias aplicáveis.

Não utilizamos os dados de pacientes para publicidade, não os vendemos e não os compartilhamos com terceiros para fins comerciais.

5. Onde os dados são armazenados

Os dados são armazenados na infraestrutura do Google Firebase (Firestore), na região southamerica-east1 (São Paulo, Brasil). O acesso a cada conjunto de dados é restrito, por regras de segurança, exclusivamente ao profissional que os criou.

6. Compartilhamento com terceiros

Utilizamos os seguintes prestadores de serviço, que podem processar dados em nome do TNCalc:

  • Google Firebase — autenticação e banco de dados.
  • RevenueCat — gerenciamento de assinaturas dentro do aplicativo.
  • Apple App Store / Google Play — processamento de pagamento de assinaturas.

Esses prestadores atuam como operadores de dados, sob instrução da Susco, e não têm autorização para usar os dados para finalidades próprias.

7. Retenção e exclusão de dados

Os dados são mantidos enquanto a conta do profissional estiver ativa. O profissional pode excluir pacientes cadastrados (conforme as regras do plano de assinatura) diretamente pelo aplicativo. Para solicitar a exclusão completa da conta e de todos os dados associados, entre em contato pelos canais indicados na seção 10.

8. Direitos do titular dos dados

Nos termos da LGPD, o titular de dados pessoais pode solicitar, a qualquer momento: confirmação da existência de tratamento, acesso aos dados, correção de dados incompletos ou desatualizados, anonimização ou eliminação de dados desnecessários, portabilidade, e eliminação dos dados tratados com consentimento. Para dados de pacientes, essas solicitações devem ser direcionadas primeiramente ao profissional de nutrição responsável pelo prontuário, que é o controlador desses dados.

9. Segurança

Adotamos medidas técnicas e administrativas para proteger os dados pessoais de acessos não autorizados e de situações de destruição, perda, alteração, comunicação ou difusão indevida, incluindo controle de acesso por conta de usuário, criptografia em trânsito e em repouso (padrão da infraestrutura Google Firebase).
