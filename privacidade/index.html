Politica de Privacidade

Support Solucoes Corporativas Ltda. (Susco)  |  CNPJ: 43.225.621/0001-86
Ultima atualizacao: 2025

Este documento descreve como a Support Solucoes Corporativas Ltda. (Susco) coleta, utiliza e protege as informacoes dos usuarios de nossos aplicativos moveis.

1. Informacoes que coletamos

Nossos aplicativos podem coletar as seguintes categorias de informacoes, conforme necessario para o funcionamento de cada servico:

  • Dados de identificacao fornecidos pelo usuario (nome, e-mail)
  • Dados de uso e interacao com o aplicativo
  • Informacoes do dispositivo (modelo, sistema operacional, identificadores anonimos)
  • Dados inseridos pelo usuario no contexto corporativo de cada app

2. Como utilizamos as informacoes

As informacoes coletadas sao utilizadas exclusivamente para:

  • Fornecer e melhorar as funcionalidades dos aplicativos
  • Garantir a seguranca e integridade dos dados corporativos
  • Comunicacoes relacionadas ao servico, quando necessario
  • Cumprimento de obrigacoes legais e regulatorias

3. Compartilhamento de dados

A Susco nao vende, aluga ou compartilha dados pessoais com terceiros para fins comerciais. Dados podem ser compartilhados somente:

  • Com provedores de infraestrutura necessarios ao funcionamento do servico
  • Quando exigido por lei ou ordem judicial
  • Com consentimento expresso do usuario

4. Armazenamento e seguranca

Os dados sao armazenados em servidores seguros e protegidos por criptografia em transito e em repouso. Adotamos praticas de seguranca alinhadas com os padroes do setor para prevenir acessos nao autorizados.

5. Seus direitos (LGPD)

Em conformidade com a Lei Geral de Protecao de Dados (Lei 13.709/2018), voce tem direito a:

  • Confirmar a existencia de tratamento de seus dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a anonimizacao, bloqueio ou eliminacao de dados desnecessarios
  • Revogar o consentimento a qualquer momento

6. Retencao de dados

Os dados sao mantidos pelo tempo necessario para a prestacao do servico ou conforme exigido pela legislacao aplicavel. Apos esse periodo, os dados sao eliminados de forma segura.

7. Cookies e tecnologias similares

Nossos aplicativos moveis nao utilizam cookies de rastreamento de terceiros. Podem ser utilizados armazenamentos locais apenas para funcionalidades essenciais do aplicativo.

8. Alteracoes nesta politica

Esta politica pode ser atualizada periodicamente. Notificaremos os usuarios sobre alteracoes relevantes por meio do proprio aplicativo ou por e-mail, quando aplicavel.
